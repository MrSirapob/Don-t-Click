# อย่ากดปุ่มนี้ v2

เกมเว็บภาษาไทยแนว **เกมตั้งใจกวนผู้เล่น** สร้างใหม่จากศูนย์

## หลักการสำคัญ

1. **ไม่มีด่านไหนผ่านเอง**
2. ทุกด่านต้องมี Player Action เป็น Win Condition
3. ทุก Trap มี Lose Condition ที่ชัดเจน
4. Timer ใช้ได้เฉพาะเปลี่ยน "สถานะของด่าน" เช่น ปุ่มจากห้ามกด -> กดได้
5. Timer ห้ามเรียก `win()` เอง
6. Engine แยกจาก Round Content
7. Round Data อยู่ใน `config.js`

## โครงสร้าง

```text
dont-click-v2/
├─ index.html
├─ README.md
└─ src/
   ├─ main.js
   ├─ config.js
   ├─ style.css
   └─ game/
      ├─ engine.js
      └─ rounds.js
```

## วิธีเพิ่มด่าน

1. เพิ่มข้อมูลใน `ROUNDS` ของ `config.js`
2. เพิ่ม `case` ใน `playRound()` ของ `rounds.js`
3. ต้องกำหนดทั้ง Win และ Lose Condition
4. ต้องทดสอบว่า reload เกมแล้วเริ่มจากรอบ 1
5. ต้องทดสอบว่ากดปุ่มกับดักแล้วจบเกม
6. ต้องทดสอบว่าทำ Win Condition แล้วไปด่านถัดไป
7. ต้องทดสอบว่า Timer ของด่านเก่าไม่ทำงานในด่านใหม่

## หมายเหตุ

เกมตั้งใจให้กวน แต่ต้องไม่ใช้ bug เป็น gameplay
ความกวนควรมาจาก **ข้อความ, การหลอก, การคาดเดาพฤติกรรม และจังหวะของเกม** ไม่ใช่จากระบบที่พัง

## Critical bug-prevention rules

- ปุ่ม gameplay ใช้ `onclick` แบบ assignment เพื่อให้สามารถเปลี่ยน handler ตาม state ได้ โดยไม่สะสม click listener
- `engine.start()` เรียก `showRound()` เพียงครั้งเดียว; ห้ามเรียก `playRound()` ซ้ำหลัง start
- ห้าม bind click handler ซ้ำกับ element เดิม
- เมื่อ state เปลี่ยน ต้องตรวจ `engine.isCurrent(token)` ก่อนทำ Win/Lose


## V3 Polish

- เมื่อแพ้ เกมจะสุ่มข้อความกวนผู้เล่นจาก `DEATH_TAUNTS` ใน `src/main.js`
- เพิ่ม class `result-loss` / `result-win` เพื่อแยกหน้าผลลัพธ์
- ปรับหน้าเล่นใหม่ให้เป็นการ์ดผลลัพธ์ที่ชัดเจนขึ้น
- เพิ่ม hover/active feedback ให้ปุ่ม
- รองรับมือถือดีขึ้น
- เพิ่ม/แก้ข้อความกวนได้ง่ายจาก array `DEATH_TAUNTS`

- เบียว/ดราม่า 10 ข้อความ
ทั้งหมดอยู่ใน `DEATH_TAUNTS` และสุ่มใช้ตอนแพ้

\n## Round-specific Death Taunts
มีข้อความกวนแบบเฉพาะด่าน **ด่านละ 10 ข้อความ ครบทั้ง 20 ด่าน = 200 ข้อความ**
- เมื่อแพ้ จะเลือกจาก pool ของด่านที่แพ้เท่านั้น
- มุกอ้างอิง mechanic ของด่านนั้นโดยตรง
- เพิ่มข้อความได้ที่ `DEATH_TAUNTS[roundNumber]`
- ไม่สุ่มข้อความของด่านอื่นมาปะปน

\n## Persona: "ผม"
ข้อความแพ้ทั้งหมดเปลี่ยนจากการพูดถึง "เกม" เป็นตัวละครผู้สร้างที่พูดกับผู้เล่นโดยตรง ใช้คำว่า "ผม" และ "คุณ"
- มุกผูกกับเหตุการณ์ของแต่ละด่าน
- ด่านละ 10 ข้อความ รวม 200 ข้อความ
- โทนสุภาพแต่กวน, แซะ, รู้ทันผู้เล่น
- สามารถต่อยอดให้ "ผม" จำจำนวนครั้งที่ผู้เล่นแพ้และเปลี่ยนบทพูดตามความสนิทได้

\n## Roast Tone
ปรับข้อความเป็นโทนกวนตีน/แซะตรงขึ้น สามารถใช้คำหยาบระดับเบาเพื่อให้ตัวละคร "ผม" มีความเป็นคนมากขึ้น
- ยังคงผูกข้อความกับแต่ละด่าน
- ด่านละ 10 ข้อความ
- รวม 200 ข้อความ
- เพิ่ม/ลดความแรงได้จาก `DEATH_TAUNTS` ใน `main.js`

\n## Subtle Roast Tone
เปลี่ยนข้อความทั้งหมดเป็นการ "ด่าแบบอ้อม ๆ" โดยตัวละคร "ผม" จะไม่เรียกผู้เล่นว่าโง่/กากตรง ๆ แต่ใช้การชมประชด ตั้งคำถาม และพูดสุภาพแบบรู้ทันแทน
- ด่านละ 10 ข้อความ
- รวม 200 ข้อความ
- แต่ละข้อความผูกกับ mechanic ของด่าน
- ตัวละครพูดกับ "คุณ" โดยตรง
